## 2. 系統是什麼？誰能用什麼？

### 2.1 系統能做什麼

華雲學校校務行政系統把學校日常的行政工作放在同一個網站裡：

| 範圍 | 內容 |
|---|---|
| 教學 | 出缺席登錄、成績登錄與成績單、操行成績、獎懲、班級點名冊、社團 |
| 學生 | 學籍資料、升級作業、學籍異動（休學、轉學、轉班）、考試分班 |
| 人事 | 教職員打卡、請假與代課、排課、聘書、臨時教師 |
| 總務 | 修繕登記、書庫、校服與簿本庫存、水電網路費用 |
| 家長與學生 | 查成績與出缺勤、請假、修改資料申請、選社、看公告 |
| 活動 | 競賽活動（報名、評審打分、公布成績、QR 碼查成績） |
| 系統 | 帳號、學年學期、公佈欄、備份、寄信 |

系統有**中文／泰文**切換，也可以用手機操作（出缺勤登錄有手機專用畫面）。

### 2.2 帳號身分

**教職員的角色：**

| 角色 | 說明 |
|---|---|
| 系統管理員 S | 最高權限，可看全部功能 |
| 系統管理員 A | 次高權限，負責重要審核（例如成績結算後修正） |
| 管理員 B | 管理員 |
| 班級導師 | 管理自己班級的學生資料、出缺席、操行、審核家長申請 |
| 任課教師 | 登錄自己任課科目的成績與出缺席 |

**部門職務（可同時身兼多個）：**

| 部門 | 職務層級 |
|---|---|
| 教務 | 主管／承辦 |
| 訓導 | 主管／承辦 |
| 總務 | 主管／承辦 |
| 開發人員 | 負責系統維護 |

> **「承辦」與「主管」的差別：** 承辦人員的新增、修改、刪除，**會先送給該部門主管核准**，核准後才真正生效。例如教務承辦修改科目比重，要教務主管核准；總務承辦更新庫存，要總務主管核准。

**其他身分：**

- **社團老師：** 被指派為某個社團的指導老師，可以使用社團點名冊與社團成績輸入。
- **臨時教師（外校支援）：** 有期限的任課教師帳號，到期日一過就自動失效、無法登入。
- **學生本人／家長：** 從家長／學生入口登入（第 11 章）。

### 2.3 資料安全

- 沒有權限的功能「根本不會出現」，直接輸入網址也會被擋下。
- 即使有人繞過畫面，**資料庫本身還有一層權限把關**，雙重保護。
- 休學、轉學、退學、畢業、肄業的學生，**資料會被隱藏**（只有教務處、管理員 A、S 看得到），家長與學生的入口帳號也會停用。
- 系統每天自動備份一次。

## 3. 登入與基本設定

### 3.1 教職員登入

1. 開啟系統網址，選「**教職員**」。
2. 輸入登入信箱與密碼。
3. **第一次登入**（或密碼被管理員重設後），系統會要求你先設定新密碼，才能繼續使用。
4. 忘記密碼：在登入畫面按「忘記密碼？」，輸入信箱，系統會寄重設信。

> 密碼如果是大家都知道的簡單密碼（例如預設密碼），系統會要求下次登入時更換。

### 3.2 登入後的首頁

- 登入後會先看到「**布告欄**」：請先看過公告，按「**我知道**」，才會進入工作分類表。
- 工作分類表分成「**教學作業**」與「**行政管理**」兩區，每個卡片是一個功能入口（例如「出缺席」「成績」「獎懲」）。
- 卡片下方的「**其他**」區有常用連結：**教職員打卡、通知、請假、課表查詢、代理人設定、競賽活動、帳號設定**（依身分顯示）。
- 「行政管理」區對有授課的老師預設收合，點一下就能展開（只是畫面整理，不是權限）。
- 畫面上方可以調整**字級（小／中／大）**、切換**中文／泰文**、按「回主選單」回到首頁。

> 首頁登入前也能看到「公佈欄」：學校最新公告在登入畫面上方就會顯示。

### 3.3 帳號設定

首頁「其他」區 →「帳號設定」：

| 項目 | 說明 |
|---|---|
| 更換登入信箱 | 輸入新信箱後，下次要用新信箱登入 |
| 通知信 | 勾選後，有新的待處理事項（例如家長帳號申請、考場名冊、審核）時，會寄信到登入信箱提醒你。**信裡只寫通知類別，不含學生個資**，詳細內容要登入系統看 |
| 更改密碼 | 需要輸入目前密碼，新密碼至少 6 碼 |

### 3.4 通知

首頁「其他」區 →「通知」：

- 家長／學生送出的基本資料修改申請、出缺勤相關訊息、代課通知、審核結果都會顯示在這裡。
- 按「**標記已讀**」整理。上方會顯示未讀數量。

### 3.5 代理人設定（出差、請假時請人接手）

首頁「其他」區 →「代理人設定」：

1. 按「新增代理」。
2. 選「被代理的人」（誰的權責要被借用）與「代理人」（誰來暫時接手）。
3. 設定開始與結束時間，可填原因（例如出差、病假），按「開始代理」。

**代理的範圍：** 只代理**一線教學工作**（點名、成績、平時表現）。**審核與行政權限不包含。**
代理期間，畫面上會用紅色提示列顯示「您目前正在代理某某老師」，右上角可以隨時結束代理。

> 外校來支援的臨時教師，請教務處先到「系統管理 → 臨時教師」建立帳號，建好後才會出現在代理人清單裡。

## 4. 老師的日常工作

### 4.1 出缺席登錄

首頁 →「**出缺席**」卡片。可用的分頁依身分而定：

| 分頁 | 誰能用 | 用途 |
|---|---|---|
| 當天 | 導師、任課教師、訓導 | 登錄今天的出缺席 |
| 一週 | 導師、任課教師、訓導 | 以一週為單位登錄或補登 |
| 紀錄查詢 | 導師、訓導 | 月報或學期累計查詢 |
| 任課班級出席查詢 | 任課教師、訓導 | 查自己任課那堂課的出缺席紀錄 |
| 全校總覽 | 訓導 | 全校出缺席狀況 |
| 示警門檻設定 | 訓導主管 | 設定示警的累計門檻 |

**出缺席的種類：** 出席、曠課、遲到、病假、事假、公假、早退。

**導師登錄（一週畫面）：**

1. 選班級，用「上一週／下一週」或「直接選擇日期」切換週次。
2. 逐格點選學生每一節的狀態，按「儲存」。
3. 可以「批次上傳」：先「下載出缺席輸入範本」（或「下載全校出缺席輸入表」，一班一個分頁），填好再上傳。
4. 填錯想還原，按「放棄變更」或「清除修改」。

**任課教師登錄（「當天」分頁，手機也適用）：**

1. 進入「出缺席」→「**當天**」，畫面會列出你**今天任課的節次**（今天沒有排課就會顯示「今天沒有排課」）。這個畫面適合用手機操作。
2. 點選學生狀態後按「儲存」。
3. 任課教師只能登錄**自己任課的節次**；導師可以直接修正自己導師班的任何節次。

**鎖定與修正：**

- 已經鎖定的出缺席，**不能直接改**。
- 任課教師：請送出「**修正申請**」，填修正理由（必填）。
- 導師：可以直接修正自己導師班。超過可直接補登的範圍時，請用上方的「**修正申請模式**」；整班已鎖定時，請按「**申請開放**」。
- 修正申請由審核者處理，處理結果會通知你。

**示警提醒：** 當某位學生「事假＋病假＋曠課」的累計達到學校設定的門檻，儲存時系統會跳出提示，問你要「**寄送通知信**」（通知家長）或「**暫不寄送**」。全校總覽中達門檻的學生會標示「⚠ 扣考參考」。

### 4.2 成績登錄

首頁 →「**成績**」卡片，進入後依身分看到分頁：

| 分頁 | 誰能用 |
|---|---|
| 學生成績登錄 | 導師、任課教師、教務 |
| 全校排行榜 | 導師、任課教師、教務 |
| 操行成績評分 | 導師、教務 |
| 班級成績總表 | 導師、教務 |
| 班級成績結果與排名 | 導師、教務 |
| 歷年成績查詢 | 導師、任課教師、教務 |

**成績的組成：** 每個科目有**期中考、期末考、平時分**三項，各自佔不同比重（由教務處每學期設定，每個年級每學期的比重加總應為 1.0）。

**登錄方式：**

1. 進入「學生成績登錄」，選班級與科目。
2. 直接在畫面輸入，或下載「成績輸入表」填好後上傳。
3. 登錄完成後，依學校規定送出並鎖定。「鎖定」也受教務處在「成績上傳時間設定」裡設定的**開放時間與鎖定**控制，過了時間或被鎖定就不能再直接改。

**幾個重要規則：**

- 「全勤／出缺席」欄位是依出缺勤紀錄**自動計算**（全勤 100 分，曠課、遲到、事假、病假依規則倒扣），不用手動輸入。
- 排名要等對應項目**鎖定後**才會顯示。
- 家長與學生看到的總分與排名，要等導師送出並鎖定平時分後才公布。
- 班級成績總表上，「綜合表現」＝敘獎分數＋學業分數，**是升級依據，不參與排名**。

**成績鎖定（結算）之後要修改：**
教務處審核 → 管理員 A 批示 →（需要時）管理員 S。核准後系統自動寫回成績；**同一個人不能連審兩關**。申請位置：首頁 →「審核中心」→「成績結算後修正」。

### 4.3 操行成績（導師）

「成績」→「**操行成績評分**」：

- 導師對本班學生做「**禮貌、衣著、服務、紀律**」四個分項評分。
- **只有導師本人與管理員看得到，任課教師看不到。**

### 4.4 獎懲登記

首頁 →「**獎懲**」卡片：

| 分頁 | 用途 |
|---|---|
| 獎懲登記 | 登記敘獎或懲處 |
| 查看獎懲 | 查已生效的獎懲紀錄（可輸入姓名或學號查詢） |

**敘獎：** 嘉獎、小功、大功。**懲處：** 警告、小過、大過。

**登錄方式：**

1. 選班級（導師，或有排課的任課教師才能登記該班）。
2. 勾選學生（可全選本班）。
3. 選類別與次數，**填寫原因（必填，整批共用）**，送出。

> **懲處和敘獎一樣要走審核**，全部通過後才會正式記錄到學生資料。老師送出後，狀態會顯示「待訓導處審核」，之後依序經過「管理員 A」，必要時再由「管理員 S」決定。審核流程見第 7.3 節。

### 4.5 班級點名冊（列印紙本）

首頁 →「**班級點名冊**」：

1. 選班級與列印方式：
   - **一週：** 不印日期，可設定每班連續列印幾頁。
   - **整學期：** 從開學日印到期末考結束，一週一頁，每天印出日期，建議**雙面列印**（每班頁數會補成偶數）。
2. 可調整「學號、姓名字體」放大倍率，以及是否加印「任課教師簽名」欄。
3. 按「列印」。格式為 **A4 直式**；雙面列印請選「**長邊翻轉**」。

**注意：**

- 名單只含**在學學生**，休學、轉學的不會出現。
- 節數依各部別（幼兒園、國小、國中、高中）的節次設定。
- 點名冊上的符號：曠課 10、遲到 1、病假 2、事假 3、公假 4、早退 5。
- 教務處可以用「編輯封面」調整整學期點名冊的封面文字與圖片。

### 4.6 社團老師

首頁 →「**社團**」卡片（被指派為社團指導老師才會看到）：

**社團點名冊：**

1. 選社團與日期。
2. 逐位學生點選出缺勤狀態（預設出席）。
3. 按「**儲存點名**」送出。也可以「列印點名冊」（1 張 A4，正反面，正面是前半學期、背面是後半學期的星期六）。

**社團成績輸入：**

1. 先選要輸入的項目：**期中考、期末考、平時分**，三項各自獨立。
2. 還沒打完先按「**暫存**」。
3. 確認無誤再按「**正式送出並鎖定**」，這一項才會回寫進學期總成績的「**才藝**」科目。
4. 已鎖定的成績要修改，請洽教務處解鎖。

### 4.7 輸入考場名單（導師）

當教務處發送考場表後，導師會收到通知：

1. 首頁 →「**考試分班**」→「輸入考場名單」。
2. 把本班學生填入分配到的考場座位（可用「隨機分配」）。
3. 全部安排完畢後，按「**完成名單**」送出。**送出即鎖定，不能再修改**，需要修改請聯繫教務處。
4. 可以按「列印本班座位表」。

### 4.8 請假與代課（老師自己請假）

首頁「其他」區 →「**請假**」：

1. 按「我要請假」，選請假起日與迄日（單日不用填迄日）、事由（選填）。
2. 系統會讀取課表，列出你請假的節次；**逐節選一位空堂老師代課**（查不到空堂老師時，可「改從全體老師選」，請自行確認對方是否真的沒課）。
3. 沒選代課老師的節次，會列在教務處的「待安排代課老師的請假」，由教務處補安排。
4. 完成後，系統會自動發**站內通知**給請假老師與代課老師。
5. 「我的請假紀錄」可以查詢，也可以「取消請假」。

> 如果帳號沒有對應到教師資料，無法自己請假，請洽教務處代為登記。

### 4.9 我的打卡紀錄

首頁「其他」區 →「**教職員打卡**」→「我的打卡紀錄」：

- 可以**依月份、依學期、依學年**查看自己的打卡。
- 如果顯示「還沒有對應到任何打卡機人員」，請洽教務處，在「教職員打卡管理 → 人員對照」把你的教師帳號對應到打卡機上的人員編號。

### 4.10 修繕登記（所有教職員）

首頁 →「**總務**」→「修繕登記」：

- 發現設備或設施損壞，任何教職員都可以在這裡「**回報新問題**」（填地點、問題描述）並「送出回報」。
- 總務處會安排處理；後續狀態（待處理、處理中、已完成）僅總務處人員可以更新。

### 4.11 課表查詢

首頁「其他」區 →「**課表查詢**」：選教師或班級，直接看整週課表。

## 5. 導師的專屬工作

導師除了第 4 章，還要處理學生與家長相關的申請。入口：首頁 →「**審核中心**」。

### 5.1 審核中心的分頁（導師常用）

| 分頁 | 內容 |
|---|---|
| 出缺勤修正／開放申請 | 處理任課教師送來的出缺席修正申請 |
| 學生資料變更通知 | 家長或學生修改基本資料後，這裡會通知你 |
| 家長／學生帳號申請 | 核對手機後核准 |
| 學生請假申請 | 家長請假，核准後寫入出缺席 |
| 學籍異動申請 | 查看休學、轉學、轉班的處理狀況，同意後立即更新名單 |
| 成績結算後修正 | 送出成績修正申請 |

### 5.2 核准家長／學生帳號申請

家長或學生第一次使用入口時，會送出申請給班導師。

1. 進入「審核中心」→「家長／學生帳號申請」。
2. 畫面會顯示**申請身分**、**申請的手機**、**學籍資料原有的電話**，請核對手機是否正確。
3. 在「**記為**」選擇身分（監護人、父親、母親），按「**核准**」。核准後手機會自動記進學籍資料，家長就能登入。
4. 可以批次勾選核准；**拒絕請逐筆處理**。

### 5.3 核准學生請假

家長在入口幫學生請假後，申請會送到這裡：

1. 「審核中心」→「學生請假申請」。
2. 看日期、節次、事由，按「**核准**」。
3. 系統會依該班當天的上課節數，把**病假或事假直接寫進出缺席表**。

### 5.4 送出學籍異動申請（休學、轉學、轉班）

導師在「**出缺席 →當天**」畫面的「**學籍異動申請**」送出（審核中心的「學籍異動申請」分頁可查看處理狀況）：

1. 選類別（休學、轉學、轉班）；轉班要再選「轉入的班級」。
2. 勾選本班同學，填寫原因（可批次勾選）。
3. 送出，等教務處同意。

**同意後的結果：**

- **休學、轉學：** 該生所有資料隱藏（僅教務處、管理員 A、S 可查閱），家長／學生入口帳號停權，**座號保留**，其他同學的號碼不變。
- **轉班：** 換到新班，**座號接在新班最後一號**。

### 5.5 學生資料變更通知

家長或學生在入口提出修改後，導師收到通知，核准或駁回。**核准前，畫面上顯示的仍是原本的資料。**

## 6. 教務處

### 6.1 學籍與學生

首頁 →「**學籍與學生**」，教務處可用的分頁：

| 分頁 | 用途 |
|---|---|
| 查詢學生 | 查全校或各班學生，點列看個人資料 |
| 新生入學登記（完整版） | 新生完整建檔 |
| 既有學生快速建檔（精簡版） | 整批匯入既有學生 |
| 學籍狀態變更 | 變更學生狀態 |
| 學期中轉班 | 學期中調班 |
| 升級作業 | 學期與學年轉換（見 6.2） |
| 年級升級對照表設定 | 設定每個年級升級後去哪裡 |
| 學生歸檔文件查詢 | 查詢上傳的歸檔文件 |
| 家長／學生登入帳號 | 查詢家長與學生的登入代碼，看哪些學生還沒有監護人資料 |

### 6.2 升級作業與學年學期

**先設定學年學期：** 首頁 →「系統管理」→「學年學期管理」：

- 新增學年度與上、下學期，設定**開始日期、結束日期**。
- 新增時會自動帶入預設日期（上學期 5/1 開學～9/30 期末；下學期 10/20 開學～隔年 3/31 期末），可在表格裡再修改。
- 按「**設為目前生效**」，這個學期就成為系統目前使用的學期。

**升級作業：**

- 只支援「**同學年 上學期 → 下學期**」或「**下學期 → 下一學年上學期**」。
- 系統會依「**年級升級對照表**」自動算出每位學生升級後該去的年級（例如國小 5 年 → 6 年、6 年 → 國中 1 年）。
- 可選擇是否「升一年級」（取消勾選＝全部留在原年級，只開新學年學籍）、是否「沿用原座號」。
- 座號預設：每班依學號由小到大重新排；也可選「先男女、再學號」。
- **舊學期的學籍與成績都會保留，不會被覆蓋。** 科目比重會自動沿用上學期，有變動的再手動修改。

> 動大筆資料之前，請先到「系統管理 → 資料中心與備份」備份。

### 6.3 成績相關設定

首頁 →「**成績**」，教務主管可用：

| 分頁 | 用途 |
|---|---|
| 成績相關設定 | **科目與比重設定**；整體佔比與加扣分規則；殘留科目清理 |
| 成績上傳時間設定 | 設定期中考、期末考、平時分、出缺勤各自的**開放時間與是否鎖定** |
| 批次列印成績單 | 多班或全校批次列印（PDF、Word 合併列印、Excel 範本） |
| 成績單樣式設定 | 調整成績單格式 |
| 成績單合併列印範本、Excel 範本 | 上傳自訂範本 |

**科目與比重：** 每學期開學前，為每個年級設定當學期的科目與比重，**同一年級同一學期的比重加總應等於 1.0（100%）**。不是 1.0 的年級，清單裡會用紅色警示。可以整批上傳 Excel（同一學年度＋學期＋年級＋科目重複上傳會直接覆蓋，填錯可改了再傳）。

**時間設定：** 可依「全校、部別、班級」三個範圍設定。**排名頁面要等對應項目鎖定後才顯示。**

### 6.4 考試分班

首頁 →「**考試分班**」→「考場編排與座位表」，流程如下：

1. **新增考試**（選學年度、學期、考試名稱，例如期中考）。
2. 系統自動把所有班級設為考場；**勾選「不擔任考場班級」**（教室不方便當考場時），按「儲存」。
3. **試算各考場人數**：依座位數比例試算，可手動修改，橫向與縱向加總一致才能儲存。
4. **產生梅花座位表並確認**：可以點一個座位再點另一個座位互換（限同一考場內）；每間考場也可以按「重新排列」。
5. 所有考場座位表都確認後，按「**發送考場表**」，通知各班導師。
6. 導師填好考場名單並送出（第 4.7 節）。
7. **所有班級都完成後**，才能一鍵下載 Excel；也可列印「座位表」與「簽到表」。

### 6.5 社團管理

首頁 →「**社團**」→「社團管理與選社設定」（教務主管）：

1. **新增社團**：名稱、名額上限（選填）、指導老師（校內教師，或填外聘老師姓名僅作紀錄）、固定上課節次（選填，有填才會同步進全校出缺席總表）、簡介。
2. **選社設定：** 選擇選社方式 —— **志願序（第一志願優先）**、**志願序（隨機亂數）**、**即時搶選**；設定最多可填幾個志願、開放與截止時間，按「儲存選社設定」。
3. **社團名單管理：** 選社團，輸入學號加入學生。
4. 學生選社與電腦抽籤分發完成後，社團老師就能使用點名冊與成績輸入。
5. 一個學生同一學期只能在一個社團。

### 6.6 排課與代課

首頁 →「**排課與代課**」→「排課與代課中心」，包含：排課工具、學校課表、代課安排、共同科目時間鎖定、課表查詢、課表資料整理。

**代課安排（教務處）：**

- 老師可自己請假並選代課老師；教務處可以「**代為輸入請假**」（臨時接到請假通知，輸入後立即生效，不用送審）。
- 「**待安排代課老師的請假**」會列出老師自己請假但沒選代課的節次，請選一位空堂老師安排。
- **同一天批次代課安排：** 多位老師同一天請假時，一次處理。
- 完成後自動通知請假老師與代課老師。

### 6.7 教職員打卡管理

首頁 →「**教職員打卡**」→「打卡管理（全校）」（教務）：

| 功能 | 說明 |
|---|---|
| 統計 | 依學期、學年、整月、單日名單檢視，可只看有異常，可匯出 Excel |
| 人員對照 | 把打卡機上的人員編號對應到教師帳號；可設定「彈性打卡」 |
| 班別與放假日 | 設定班別（同一人可掛多個）、全校放假日。放假日不判缺勤、不計入應到天數 |
| 補卡／更正 | 補打卡、單日更正（請假、公出、視為正常、休假）、作廢誤刷（都要填原因） |
| 匯入與同步 | 上傳打卡機 CSV（重複的打卡會自動略過），並顯示資料庫中最新一筆打卡時間 |

> 如果超過 3 天沒有新資料，系統會提醒你檢查學校電腦的自動同步是否正常。沒有設定班別的人員，不會判斷遲到或缺勤。

### 6.8 聘書

首頁 →「**聘書**」：歷年教師資料、自聘教師聘書、當年教師聘書，並可列印。

### 6.9 臨時教師（外校支援）

首頁 →「系統管理」→「臨時教師（外校支援）」：

1. 按「新增臨時教師」，填姓名、信箱、所屬學校／單位。
2. 設定**到期日**；**臨時密碼**有填就直接建立帳號，留空就寄邀請信。
3. 帳號身分是任課教師，到期日一過自動失效、無法登入。
4. 可以「延長／改到期日」或「立即停用」。建立後就能被選為代理人。

### 6.10 教師代辦專區

首頁 →「系統管理」→「**教師代辦專區**」（管理員 S／A／B 可用）：選一位老師，直接進入他的功能（成績登錄、出缺席登錄、操行成績、獎懲登記、考場名單、社團點名冊等），**代為上傳、下載與小範圍修正**。也有全校性的檔案上傳／下載（成績輸入表、出缺席輸入表、班級成績總表）。

### 6.11 審核中心（教務相關）

| 分頁 | 內容 |
|---|---|
| 成績結算後修正 | 審核成績鎖定後的修正申請 |
| 學生資料變更通知 | 學籍重要欄位的變更 |
| 學籍異動申請 | 休學、轉學、轉班，同意後立即更新 |
| 家長／學生帳號申請 | 代為處理 |
| 送審總覽（主管） | 所有待主管核准的送審清單 |

## 7. 訓導處

### 7.1 出缺席

首頁 →「**出缺席**」，訓導處可以用：當天、一週、紀錄查詢、任課班級出席查詢、**全校總覽**、**示警門檻設定**（主管）。

**全校出缺席狀況總覽：**

- 顯示全校學生的「事假＋病假＋曠課」累計，可勾選「**只顯示達門檻的學生**」，也能用姓名或學號搜尋。
- 達標的學生會標示「⚠ 扣考參考」，並顯示導師最新的處理紀錄。

**示警門檻設定：** 設定事假、病假、曠課累計達多少時示警。僅訓導處人員使用。

### 7.2 出缺勤修正審核

「審核中心」→「出缺勤修正／開放申請」：

- **整週／當天出缺席修正申請：** 審核老師送來的修正，可「**同意**」、「**不同意**」，或「**送管理員 S 決定**」。
- **單格補登／範圍開放申請：** 舊流程，可「**核准**」或「**駁回**」。

### 7.3 獎懲審核

獎懲（敘獎與懲處）送出後要走審核：
審核關卡依序是：

| 關卡 | 狀態顯示 | 誰審核 |
|---|---|---|
| 第一關 | 待訓導處審核 | 訓導處人員（以及系統管理員 S） |
| 第二關 | 待管理員 A 審核 | 管理員 A |
| 第三關（必要時） | 待管理員 S 審核 | 系統管理員 S |

1. 有審核權限的人進入「**獎懲登記**」，在「待您審核的敘獎／懲處申請」區看到輪到自己的申請（表格的「關卡」欄會顯示目前在哪一關）。
2. 可以「**同意勾選項目**」、「**不同意勾選項目**」。
3. 管理員 A 可以把勾選的申請「**改送管理員 S 決定**」（只能用在「待管理員 A 審核」的申請）。
4. 訓導處人員或系統管理員自己登記的獎懲，會**直接進入「待管理員 A 審核」**。
5. **全部通過後**，才會正式記錄到學生資料。

### 7.4 審核中心（訓導相關）

出缺勤修正／開放申請、送審總覽（主管）。

## 9. 系統管理

首頁 →「**系統管理**」。以下功能依身分顯示。

| 分頁 | 誰能用 | 用途 |
|---|---|---|
| 資料中心與備份 | 開發人員 | 四部門 Excel 一鍵下載／上傳、JSON 備份與還原、其他檔案上傳入口 |
| 學年學期管理 | 開發人員 | **新學年、新學期開始時先設定** |
| 帳號管理 | 開發人員 | 建立帳號、重設密碼、指派部門職務 |
| 臨時教師（外校支援） | 教務、開發人員 | 見 6.9 |
| 教師代辦專區 | 教務、開發人員 | 見 6.10 |
| 公佈欄管理 | 開發人員、管理員 | 發布公告 |
| 系統文字與背景音樂 | 系統管理員 S | 調整系統文字 |
| 寄信設定 | 開發人員、管理員 S／A | 通知信狀態、寄測試信 |
| 資料檢查（教師／班級） | 開發人員 | 匯入課表或名單後檢查，有重複時合併 |

### 9.1 備份與還原

- **動大筆資料之前，一定要先備份。**
- 「資料中心與備份」可以下載 **JSON 備份檔**（完整、含全部出缺勤，適合災難復原），也可以還原。
- 系統每天**自動備份**，保留最近幾份；也建議在重要時間點（學期結束、升級作業前）手動下載一份存到隨身碟或雲端。
- 「四部門 Excel」可以一鍵下載或上傳教務、總務、訓導、開發人員的全部資料表，方便對照與編修。

### 9.2 帳號管理

- **新增教師帳號：** 填姓名、角色、信箱；「初始密碼」有填（至少 6 碼）就直接建立可登入帳號、不寄信。
- **重設密碼、更換信箱、編輯角色。**
- **部門職務指派：** 勾選教務／訓導／總務／開發人員，並設定「主管」或「承辦」。可以一次調整很多人，最後按一次「**全部儲存**」；有修改的列會用黃底標示。
- **帳號可見內容（個別調整）：** 對單一帳號加開或關閉特定功能。
- **孤兒帳號：** 信箱已註冊但清單裡看不到的帳號，補上姓名與角色就能正常使用，不用刪除重建。
- **重複資料提示：** 系統會自動偵測姓名很像的既有教師資料，跳出提示讓你確認是不是同一個人。
- 下方有「帳號異動紀錄」（角色變更、密碼重設）可查。

### 9.3 公佈欄

「公佈欄管理」：

- 最新已發布的一篇會在**首頁登入卡片上方用縮圖顯示**，接下來 4 篇只顯示標題。
- 每篇可設定「**顯示幾天**」，天數一到自動隱藏（這裡仍看得到，標示「已過期」）；需要長期公告請勾選「**永久保存**」。
- 要重新發布過期公告：按「編輯」，勾選「**從今天重新起算**」。
- 取消勾選「發布」＝存成草稿，首頁不會顯示。

### 9.4 寄信設定

查看通知信的狀態（已設定的寄信方式與寄件人），並可寄測試信。

### 9.5 開發人員區的其他設定

- **密碼政策設定。**
- **教師登入首頁設定：** 單純的任課或導師登入後，直接進入哪個頁面。
- **班級成績總表：** 出缺席分數排除設定。
- **出缺席登錄：** 導師協助任課教師點名的設定。

### 9.6 管理員的「身分切換」

管理員帳號可以用右上角的「**代理／視角**」切換成**教師視角**，預覽一般教師看得到的畫面（畫面上會顯示「預覽教師畫面」提示）。

## 10. 審核流程總表

| 事項 | 誰申請 | 誰審核 | 核准後 |
|---|---|---|---|
| 家長／學生帳號申請 | 家長、學生 | 班導師（核對手機） | 手機記入學籍資料，帳號可登入 |
| 家長修改基本資料 | 家長、學生 | 班導師 | 更新學籍或監護人資料 |
| 學生請假 | 家長 | 班導師 | 病假／事假直接寫入出缺席 |
| 學籍異動（休學、轉學、轉班） | 導師 | 教務處 | 立即更新名單；休學、轉學者資料隱藏、入口停權 |
| 出缺席修正（已鎖定） | 任課教師 | 審核者，可送管理員 S 決定 | 修正生效 |
| 成績結算後修正 | 教師 | 教務處 → 管理員 A →（需要時）管理員 S | 系統自動寫回成績；同一人不能連審兩關 |
| 獎懲（敘獎、懲處） | 導師、任課教師 | 訓導處 → 管理員 A →（必要時）管理員 S | 全部通過後才正式記錄 |
| 承辦人員的新增／修改／刪除 | 教務、訓導、總務承辦 | 該部門主管 | 才真正生效 |
| 教師請假 | 老師自己 | 不需審核 | 立即生效，通知請假與代課老師 |
| 教務處代為輸入請假 | 教務處 | 不需送審 | 立即生效 |

## 11. 家長與學生入口

### 11.1 登入

1. 開啟系統網址，選「**家長/學生登入口**」。
2. **登入代碼：**
   - 家長：**HY＋學號**（例如 HY0123）
   - 學生：**HYS＋學號**（例如 HYS0123）
3. **密碼：你的手機號碼。** 家長用**任何一位監護人登記的手機號碼**都能登入。
4. **第一次使用：** 輸入代碼與手機後，按「**第一次使用？申請帳號**」。申請會送給**班導師**核對手機號碼，核准後手機會自動記進學籍資料，就能登入。
5. 如果顯示「代碼與手機不相符」，代表這支手機還沒登記，請聯絡導師。

> 尚未登記監護人資料的學生，需要先由學校補上才能登入。

### 11.2 能看什麼

登入後的「家長／學生查詢入口」上方有五個分頁：**成績、教師/班級課表、獎懲、請假、通知**，可以看到：

| 項目 | 說明 |
|---|---|
| 本學期各期成績和排名（「成績」分頁） | 期中、期末、平時、總表；**總分與排名要等導師送出並鎖定平時分後才會公布** |
| 歷年成績（「成績」分頁） | 點選「各科」展開該學期各科成績；總分與排名要等學校設定好科目比重並公布後才顯示 |
| 出缺勤彙總（「成績」分頁） | 依學期，預設顯示本學期，點次數可看到登記的日期。**已達學校示警門檻的一半時會有提醒** |
| 教師／班級課表（「課表」分頁） | 孩子的班級課表 |
| 獎懲紀錄（「獎懲」分頁） | 最近的獎懲 |
| 學校公告（「通知」分頁） | 公佈欄 |
| 學籍資料與監護人資料（頁面下方） | 個人資料 |
| 通知（「通知」分頁） | 有新內容時會標示「● 通知有新內容」，也包含修改資料申請進度 |

### 11.3 修改資料申請

1. 在「學籍資料」或「監護人資料」，**直接點選標黃色的欄位**修改。
2. 改完按下方「**送出申請**」一起送出。
3. 送出後導師會立即收到通知，**需經導師核准才會正式更新**。核准前，畫面上顯示的仍是原本的資料。
4. 申請進度可在「通知」分頁，或「修改資料申請進度」查看。

### 11.4 請假申請（家長帳號）

1. 在「**請假**」分頁填寫：日期、請假原因（例如發燒看醫生）。
2. 可以「**只請部分節次**」（只能選同一天；不勾就是整天）。
3. 送出後由**班導師審核**，同意後才會登記進出缺席表。**只能補請最近 14 天內的假。**
4. 請假申請需要由**家長帳號**送出；學生帳號可以查看請假紀錄。

### 11.5 社團選社（學生本人）

1. 學生用**學生本人帳號**登入，按「**社團／才藝課選社 →**」。
2. 教務處開放選社時間內，依喜好程度**依序選填志願**（志願一最優先，可以不用填滿）；若教務處設定為「即時搶選」，則直接選。
3. 家長帳號不能代替學生選社。
4. 不在開放時間內，會顯示「目前不在開放時間內」。電腦抽籤完成後，如果沒有顯示分發到的社團，請洽教務處。

### 11.6 競賽活動

按「**競賽活動 →**」可以報名賽事、查看成績與公告，詳見第 12 章。

## 12. 競賽活動

競賽活動是校內活動的報名與成績系統，**任何老師都可以建立賽事**（建立者就是承辦人）。

- **老師與學生入口：** 首頁「其他」區的連結（老師）或入口頁的「競賽活動 →」按鈕（學生）。
- **學生報名：** 用學生本人帳號，系統依年級自動分組。
- **評審：** 校內老師用自己的帳號打分；外聘評審用承辦人建立的訪客帳號（只能使用競賽功能）。
- **成績：** 先公布，之後若有更動，必須寫修正說明並自動發出修正公告。
- **外校與家長：** 掃 QR 碼即可查成績，不用登入。
- **辦完的賽事：** 改成「已結束」會自動收到列表下方；建錯的賽事可以刪除。

完整步驟請看《競賽系統操作說明.md》。

## 13. 常見問題

**Q：我登入後找不到某個功能？**
系統依身分顯示功能。若您認為需要，請洽教務處調整身分或部門職務。

**Q：忘記密碼怎麼辦？**
教職員：登入畫面按「忘記密碼？」。家長與學生：密碼是手機號碼，如果更換了手機號碼，請聯絡導師更新。

**Q：出缺席已鎖定，要怎麼改？**
任課教師：送「修正申請」並填理由。導師：直接修正自己班，或按「申請開放」。

**Q：成績鎖定後發現打錯了？**
走「審核中心 → 成績結算後修正」，經教務處、管理員 A 審核後系統自動寫回。

**Q：家長說看不到成績排名？**
排名要等導師送出並**鎖定**平時分，並且學校設定好科目比重後才公布。

**Q：家長說登入不了？**
確認登入代碼是 HY＋學號（學生是 HYS＋學號）、密碼是手機號碼，且該手機已登記在監護人資料。第一次使用要先申請帳號，等導師核准。

**Q：學生休學或轉學後，資料還看得到嗎？**
該生的資料會被隱藏，僅教務處、管理員 A、S 可查閱；家長與學生入口帳號會停用。

**Q：我自己請假後，要找代課老師嗎？**
請假時就可以逐節選空堂老師代課。沒選的節次，教務處會補安排。

**Q：要離開學校一段時間，怎麼請人接手我的工作？**
用「代理人設定」指定代理人與時間。代理只包含一線教學工作，不含審核與行政權限。

**Q：網站打不開或很慢？**
先確認網路連線，重新整理頁面。持續有問題請洽教務處或系統管理員。

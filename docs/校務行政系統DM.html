出缺席・成績・請假・競賽，一個網站全部搞定
老師省時間，家長更安心
把學校每天的行政工作搬上網。老師少填表單、少跑辦公室，家長與學生用手機就能查詢與申請，學校的每一次審核與修改都有紀錄可查。
📋

出缺席登錄

任課老師用手機就能點名，導師一週批次上傳。事假、病假、曠課累計達門檻，自動提醒。

📊

成績與成績單

期中、期末、平時分線上登錄，自動算班排名與年級排名；成績單可批次列印（PDF／Word／Excel）。

👪

家長與學生入口

用手機號碼登入，查成績、出缺勤、獎懲、課表；線上請假、申請修改資料，不用再跑學校。

✅

審核線上化

請假、學籍異動、獎懲、成績修正，一關一關線上核准，每一步都留下紀錄。

🎨

社團與選社

學生線上填志願，電腦抽籤分發；社團老師線上點名與輸入成績。

🪑

考試分班

自動編排考場與梅花座位表，一鍵發送考場表給導師，並列印座位表與簽到表。

🕘

打卡・請假・代課

教職員查詢打卡紀錄；請假時逐節選代課老師，系統自動通知雙方。

🏆

競賽活動

線上報名、評審手機打分、成績公布；外校與家長掃 QR 碼就能查成績。

依身分顯示功能資料庫權限雙重把關每日自動備份中文／泰文雙語手機友善

三分鐘開始使用

老師、家長、學生，各有自己的入口

老師

  1. 開啟系統網址，選「教職員」
  2. 輸入登入信箱與密碼（第一次登入會要求先改密碼）
  3. 看過布告欄，按「我知道」進入工作分類表
  4. 依您的身分，自動顯示可用的功能

家長

  1. 開啟系統網址，選「家長/學生登入口」
  2. 輸入登入代碼與手機號碼
  3. 第一次使用請按「申請帳號」，導師核對手機後核准
  4. 可查成績、出缺勤、獎懲、課表，也能線上請假
登入代碼：HY＋學號
密碼：您的手機號碼

學生

  1. 使用學生本人的登入代碼登入
  2. 查詢自己的成績與出缺勤
  3. 開放時間內可線上選社，也能報名競賽活動
登入代碼：HYS＋學號
密碼：您的手機號碼

給家長的小提醒

  • 成績與排名，要等導師送出並鎖定平時分、學校公布後才會顯示。
  • 孩子的出缺席累計達到學校示警門檻的一半時，入口頁會提醒您多留意。
  • 線上請假只能補請最近 14 天內的假，並由家長帳號送出；可以只請部分節次。
  • 修改資料送出後，導師核准前畫面上仍顯示原本的資料，進度可在「通知」查看。
